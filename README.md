# Agent 记忆模块：B 端平台落地教材

一份面向“第一次做记忆模块”的团队教材：从边界、准入、架构、字段模型，到写入、召回、治理、平台接入，再到一个车企 CRM 的三类角色实战模块。

## 在线阅读

在线阅读：https://anthony67158.github.io/agent-memory-textbook/

## 本地查看

直接用浏览器打开 `index.html`。页面是单文件 HTML，图形在 `assets/` 下，均为 SVG。

## 内容结构

1. 先定边界：记忆不是聊天记录
2. 准入：什么该进记忆
3. 架构：六层平台怎么分
4. 模型：Identity + Content + Policy
5. 写入：从事件到可召回
6. 召回：从候选到证据包
7. 治理：B 端的生死线
8. 接入：五阶段上线
9. 推进：团队与 8 周排期
10. 坑与清单
11. 从零接手：CRM Agent 记忆模块怎么干（角色访谈、场景评分、记忆盘点、字段模型、权限交接、12 周试点）
